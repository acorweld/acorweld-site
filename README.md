# ACorWeld

Source for [acorweld.com](https://acorweld.com) — the personal site of Maciej Kochel, an independent welding and coating inspector (IWE, FROSIO Level III).

Static HTML/CSS/JS, no framework or build step, hosted on GitHub Pages with a custom domain. Fonts and images are self-hosted; analytics via [GoatCounter](https://www.goatcounter.com/) (cookie-free).
